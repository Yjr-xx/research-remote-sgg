### 环境的建立方式（可复现）

```bash
# 系统 python3 建不出带 pip 的 venv，改用 anaconda 的解释器（它带 ensurepip）
/opt/anaconda3/bin/python -m venv ~/venv/sgg
source ~/venv/sgg/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cu121
```

环境建在用户目录下，**不需要 sudo，不影响其他成员**。
