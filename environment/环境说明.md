## 三、环境复现（老师 1.2 第 5 条）

老师原文是「维护 `requirements.txt` **或** `environment.yml`」，本仓库用前者：

```bash
# 重建步骤（在一台干净机器上）
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r environment/requirements.txt
```
